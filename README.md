# To-Do List (DevOps Project 2)

A simple command-line to-do list app built in Python as part of the DevOps internship Week 2 Git/GitHub project.

## Features
- Add tasks
- Remove tasks
- Display numbered task list

## Installation
```bash
git clone https://github.com/Evelyin405/todo-list-devops.git
cd todo-list-devops
```

## Usage
```bash
python todo.py
```
